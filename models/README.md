# Model metadata in this export

These folders contain model cards, configs, tokenizer files and manifests for
the Stage-2 base and Manager-SLM v1. They contain **no model or adapter weights**.
`MANIFEST.json` records the original research release, including weight files
that are intentionally absent from this public portfolio export. A clone of
this export cannot load either derived model for inference.

The original Qwen3-0.6B base model must be obtained from its provider under its
own license. Reconstructing the derived models also requires the training data
and workflow described in the source code; restricted datasets are not
distributed here.
